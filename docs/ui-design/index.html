teamem portal — Web UI 设计稿

M2 里程碑全页面设计。产品核心叙事：知识从真实开发活动中"编译"而来，每一条都带可回溯的证据—— 本套设计围绕证据、溯源、可信度展开，而非普通 wiki。点击任意页面预览； 页面顶部的 PREVIEW 工具条可切换状态（空态/错误态/降级态等）与明暗主题。
